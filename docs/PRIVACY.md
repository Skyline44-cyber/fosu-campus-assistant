# 隐私说明

## 本机保存的内容

- 房间名称、校区、估算电价
- 学期开始日期、总周数、节次时间表
- 电费记录：日期、余额、电表读数、备注、来源
- 课程：名称、教师、地点、星期、节次、周次、颜色

这些数据保存在应用私有目录的 `SharedPreferences`：

```text
/data/data/dev.campususage.fosu[.debug]/shared_prefs/fosu_campus_data_v1.xml
```

普通用户无法直接访问；Root 或设备调试权限可能读取。

## 网络与登录

App 声明 `INTERNET` 权限，用于：

- 在 App 内打开 `https://i.chaoxing.com/`，由学习通官方页面完成登录；
- 加载 `passport2.chaoxing.com`、`i.chaoxing.com` 和 `kb.chaoxing.com` 的学习通页面/接口；
- 打开企业微信「佛大一卡通」官方入口；如未安装企业微信，则打开腾讯官方网页。

登录时：

- 账号、密码、验证码输入到**学习通自己的网页**；
- App 不读取、不保存学习通密码；
- 登录 Cookie 由 Android WebView 的 `CookieManager` 保存，用于继续访问学习通；
- 可在「我的 → 清除学习通登录」删除 Cookie 和 WebStorage。

学习通全部使用 HTTPS；App 不再放行 `100.fosu.edu.cn` 或其他明文域名。

## 不收集的内容

- 学习通账号、密码、登录输入框内容
- 微信/企业微信账号、OpenID、聊天记录
- 小程序缓存或页面截图
- 精确位置、通讯录、相册、设备标识
- 使用统计、崩溃上报、广告标识

## 课表数据

课表同步使用 Android 原生 HTTPS 请求，不在 WebView 中执行页面提取脚本：

- 只向学习通课表接口提交 `week` 参数；
- 只读取课程名、教师、地点、星期、节次、周次；
- 不读取备注、成绩、账号资料或页面 HTML；
- 不向任何自建服务器上传。

## 备份

「我的 → 数据」支持复制或分享 JSON 备份。备份是明文，包含房间、账单与课程和节次时间，不包含学习通密码或 WebView Cookie。分享到聊天工具或云盘后，请自行管理访问权限。

系统云备份和换机迁移均在 Manifest 与 `data_extraction_rules.xml` 中关闭，备份文件只能由用户主动导出。

## 删除

- 单条电费可在电费页删除。
- 单门课程可在课表列表删除。
- 「我的 → 数据 → 清空数据」删除全部本地内容。
- 「我的 → 清除学习通登录」删除 WebView 登录状态。
- 卸载应用会删除整个私有目录。
